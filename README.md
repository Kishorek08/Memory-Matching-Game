# 🎮 Memory Matching Game

A fun and interactive **Memory Match Game** built using **HTML**, **CSS**, and **JavaScript**.  
Flip cards, find matching pairs, and test your memory skills!

---

## 🚀 Features
- 🃏 Card flipping animation  
- 🎯 Matching logic  
- 🔁 Restartable game  
- 🔒 Prevents clicking during mismatch animations  
- 🧩 Randomized card positions every game  

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript (ES6)

---

## ▶️ How to Play
1. Open `index.html` in your browser  
2. Click on a card to flip it  
3. Flip a second card  
4. If both match — they stay flipped  
5. If not — they flip back  
6. Match all pairs to win!
